# Power BI Dashboard — Step-by-Step Build Guide

This guide walks you through recreating the analytics dashboard in Microsoft Power BI Desktop.
You will need the CSV files generated by the ETL pipeline (in `data/processed/`).

Estimated time: 3–5 hours.

---

## Prerequisites

- Download **Power BI Desktop** (free): https://powerbi.microsoft.com/desktop
- Run `etl/pipeline.py` first to generate all the CSV files in `data/processed/`
- Open Power BI Desktop

---

## Part 1 — Load the data (15 min)

### Step 1: Import the processed CSV files

1. Open Power BI Desktop
2. Click **Home → Get Data → Text/CSV**
3. Navigate to your `data/processed/` folder and load these files:
   - `monthly_revenue.csv`
   - `rfm_segments.csv`
   - `rfm_summary.csv`
   - `cohort_pivot.csv`
   - `avg_retention.csv`
   - `churn_risk.csv`
   - `region_performance.csv`
   - `kpi_summary.csv`
   - `category_performance.csv`
   - `payment_methods.csv`
   - `channel_performance.csv`
4. For each file, click **Load** (not Transform — the data is already clean)

### Step 2: Also load the raw tables

Load these four files from `data/raw/`:
- `orders.csv`
- `order_items.csv`
- `customers.csv`
- `products.csv`

## Part 2 — Set up relationships (10 min)

Click the **Model view** icon on the left (looks like three connected boxes).

Create these relationships by dragging from one column to another:

| From (many side) | Column | To (one side) | Column |
|---|---|---|---|
| orders | customer_id | customers | customer_id |
| order_items | order_id | orders | order_id |
| order_items | product_id | products | product_id |

**Check each relationship:**
- Cardinality should be **Many to one (*)→(1)**
- Cross-filter direction: **Single**

> Tip: If Power BI auto-detected any wrong relationships, delete them first, then create the correct ones manually.

### Fix column data types

Go to **Model view → click each table**, then check:

| Table | Column | Correct Type |
|---|---|---|
| orders | order_date | Date |
| order_items | quantity | Whole Number |
| order_items | unit_price | Decimal Number |
| order_items | return_flag | Whole Number |
| monthly_revenue | revenue | Decimal Number |

To change: select the column → **Column tools tab → Data type dropdown**

## Part 3 — Create DAX measures (30 min)

Go to **Report view**. Right-click the `orders` table in the Fields pane → **New measure**.
Paste each measure below.

### Revenue & orders

```dax
Total Revenue =
CALCULATE(
    SUMX(order_items, order_items[quantity] * order_items[unit_price]),
    orders[status] = "Delivered"
)
```

```dax
Total Orders =
CALCULATE(
    DISTINCTCOUNT(orders[order_id]),
    orders[status] = "Delivered"
)
```

```dax
AOV =
DIVIDE([Total Revenue], [Total Orders], 0)
```

```dax
Gross Profit =
CALCULATE(
    SUMX(
        order_items,
        order_items[quantity] *
        (order_items[unit_price] - RELATED(products[cost_price]))
    ),
    orders[status] = "Delivered"
)
```

```dax
Gross Margin % =
DIVIDE([Gross Profit], [Total Revenue], 0)
```

```dax
Return Rate % =
CALCULATE(
    DIVIDE(
        COUNTROWS(FILTER(order_items, order_items[return_flag] = 1)),
        COUNTROWS(order_items),
        0
    )
)
```

### Month-over-month growth

```dax
MoM Growth % =
VAR current_month = [Total Revenue]
VAR prev_month    = CALCULATE([Total Revenue], DATEADD(orders[order_date], -1, MONTH))
RETURN DIVIDE(current_month - prev_month, prev_month, BLANK())
```

### Customers & churn

```dax
Unique Customers =
CALCULATE(
    DISTINCTCOUNT(orders[customer_id]),
    orders[status] = "Delivered"
)
```

```dax
Churn Rate % =
VAR cutoff_date = DATE(2011, 6, 9)
VAR churned =
    COUNTROWS(
        FILTER(
            VALUES(orders[customer_id]),
            CALCULATE(MAX(orders[order_date])) < cutoff_date
        )
    )
RETURN DIVIDE(churned, [Unique Customers], 0)
```

### RFM segment label (calculated column — not a measure)

Right-click `rfm_segments` table → **New column**:

```dax
Segment Label =
VAR r = rfm_segments[r_score]
VAR f = rfm_segments[f_score]
VAR m = rfm_segments[m_score]
RETURN
SWITCH(TRUE(),
    r >= 4 && f >= 4 && m >= 4,          "Champions",
    f >= 4 && r >= 3,                     "Loyal Customers",
    r >= 4 && f < 3,                      "Potential Loyalists",
    r <= 2 && f >= 3,                     "At Risk",
    r = 1  && f >= 4 && m >= 4,           "Cannot Lose Them",
    r <= 2 && f <= 2 && m <= 2,           "Hibernating",
    r = 1,                                "Lost",
    "Others"
)
```

## Part 4 — Build the dashboard pages (2–3 hours)

### Apply the dark theme first

1. **View → Themes → Browse for themes**
2. Select the `powerbi/theme.json` file in this project
3. This sets the dark background and purple accent colours

If you want to set it manually:
- Select all visuals → **Format → Background → colour #1a1d2e**
- Canvas background: **Format → Wallpaper → colour #0f1117**

---

### Page 1: Executive Summary

**Right-click the page tab → Rename → "Summary"**

**KPI cards (top row):**
1. Click the **Card** visual (box with a big number in it)
2. Drag `[Total Revenue]` into Fields
3. Format: **Format visual → Callout value → Font size 28**
4. Turn off the category label
5. Repeat for: `[Total Orders]`, `[AOV]`, `[Gross Margin %]`, `[Return Rate %]`, `[Churn Rate %]`
6. Arrange all 6 cards in a row at the top

**Revenue trend:**
1. Click **Line chart**
2. X-axis → `monthly_revenue[month]`
3. Y-axis → `monthly_revenue[revenue]`
4. Add a second Y-axis line for MoM growth:
   - Click the visual → Format → **Add Y-axis** → drag `monthly_revenue[mom_growth_pct]`

**Category breakdown:**
1. Click **Clustered bar chart**
2. Y-axis → `category_performance[category]`
3. X-axis → `category_performance[revenue]`
4. Sort: click `...` on the chart → Sort by revenue → Descending

---

### Page 2: Customer Segments

**Add a new page, name it "Customers"**

**RFM treemap:**
1. Click **Treemap** visual
2. Category → `rfm_summary[segment]`
3. Values → `rfm_summary[total_revenue]`
4. Tooltips → `rfm_summary[customers]`, `rfm_summary[avg_spend]`

**Churn donut:**
1. Click **Donut chart**
2. Legend → `churn_risk[churn_status]`
3. Values → count of `churn_risk[customer_id]`
4. Format → Data colours:

   - Churned → #ef4444 (red)

**Segment bar chart:**
1. Click **Clustered bar chart**
2. Y-axis → `rfm_summary[segment]`
3. X-axis → `rfm_summary[total_revenue]`
4. Sort descending by revenue

**RFM scatter:**
1. Click **Scatter chart**
2. X-axis → `rfm_segments[recency_days]`
3. Y-axis → `rfm_segments[monetary]`
4. Size → `rfm_segments[frequency]`
5. Legend → `rfm_segments[segment]`

### Page 3: Cohort Retention

**Add a new page, name it "Retention"**

**Cohort heatmap (using Matrix visual):**

The `cohort_pivot.csv` already has one row per cohort month and columns M00–M11.

1. Click **Matrix** visual
2. Rows → `cohort_pivot[cohort_month]`
3. Values → drag all columns: M00, M01, M02 ... M11
4. **Format → Cell elements → Background color → Turn ON**
5. Set: Format style = **Gradient**, Min = white, Max = #7c3aed (purple)
6. Apply to all value columns

> This gives you the heatmap effect with colour intensity matching retention %.

**Retention line chart:**
1. Click **Line chart**
2. X-axis → `avg_retention[period]`
3. Y-axis → `avg_retention[avg_pct]`
4. Add lines for min_pct and max_pct as additional measures

---

### Page 4: Funnel & A/B Test

**Add a new page, name it "Funnel"**

Power BI doesn't have a native funnel chart in older versions.
Two options:

**Option A (recommended): Use a Funnel chart visual**
1. Click the **Funnel** visual (if available in your version)
2. Values → measure for each stage count
3. Category → stage names

**Option B: Use a custom visual**
1. Click **Get more visuals** in the visualisations pane
2. Search for "Funnel Chart" → add it
3. Configure with your stage data

**A/B test results card:**
Since the A/B test is computed in Python, display the results as a text card:
1. Insert → **Text box**
2. Type the key results:
   ```
   A/B Test Results
   Revenue lift: +16.9% (Mann-Whitney U, p < 0.001) ✅
   CVR lift: +11.5% (Chi-Square, p < 0.001) ✅
   Recommendation: Ship the new checkout.
   ```

## Part 5 — Add slicers and interactivity (20 min)

**Add slicers on each page:**
1. Click **Slicer** visual
2. Field → `orders[order_date]`
3. Format → Slicer settings → Style: **Between** (gives a date range picker)

**Add more slicers for:**
- `customers[region]` — style: Dropdown
- `rfm_segments[segment]` — style: List

**Sync slicers across pages:**
1. **View → Sync slicers**
2. A panel opens showing which pages each slicer applies to
3. Check all pages for the date slicer so it works everywhere

**Add drill-through:**
1. On the Regional page, right-click a region bar → **Drill through**
2. Or set up manually: on the target page, drag a field into **Drill-through filters**
3. Add a Back button: **Insert → Buttons → Back**

## Troubleshooting

| Problem | Fix |
|---|---|
| "Can't create relationship" | Check for duplicate values — relationships need unique keys on the "one" side |
| Date slicer shows as text | Select the date column → Column tools → Data type → Date |
| Numbers showing wrong | Check the column is Decimal Number, not Text |
| Heatmap colours not showing | Make sure M00–M11 columns are Decimal Number type |
| Measures show BLANK | Check your filter context — the measure might need `REMOVEFILTERS()` |

## Useful DAX patterns

```dax
-- Year-to-date revenue
YTD Revenue = TOTALYTD([Total Revenue], orders[order_date])

-- Same period last year
SPLY Revenue =
CALCULATE([Total Revenue], SAMEPERIODLASTYEAR(orders[order_date]))

-- % share of a segment vs total
Segment Share % =
DIVIDE([Total Revenue], CALCULATE([Total Revenue], ALL(rfm_segments[segment])))

-- Rolling 3-month average
Rolling 3M Revenue =
AVERAGEX(
    DATESINPERIOD(orders[order_date], LASTDATE(orders[order_date]), -3, MONTH),
    [Total Revenue]
)
```
