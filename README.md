# E-Commerce Sales & Customer Behaviour Analytics

End-to-end analytics project on real transaction data from a UK-based online gift retailer.
Covers the full data science workflow — data cleaning, SQL analysis, RFM segmentation,
cohort retention, A/B hypothesis testing, an interactive dashboard, and a Power BI guide.

**Dataset:** UCI Online Retail II — 802,890 real transactions (Dec 2009 – Dec 2011)
**Source:** https://archive.ics.uci.edu/dataset/502/online+retail+ii

## Setup

```bash
git clone https://github.com/Codex610/E-Commerce-Sales-Customer-Behaviour-Analytics-Dashboard
cd E-Commerce-Sales-Customer-Behaviour-Analytics-Dashboard

python -m venv venv
source venv/bin/activate      # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

Download the dataset from https://archive.ics.uci.edu/dataset/502/online+retail+ii
and place `online_retail_II.xlsx` in the `data/` folder.

---

## Running the project

Run in this order:

```bash
# 1. Clean and load the data (~3 min — reads the 44MB Excel file)
python 1_load_data.py

# 2. Run ETL pipeline — creates SQL views and exports all processed CSVs
python etl/pipeline.py

# 3. EDA and RFM charts (saves 13 HTML files to charts/)
python notebooks/01_eda_and_rfm.py

# 4. A/B testing and hypothesis tests (saves 2 more charts)
python notebooks/02_ab_testing.py

# 5. Interactive dashboard
python dashboard/app.py
# open http://127.0.0.1:8050
```

Charts are saved to `charts/` — open any `.html` file in your browser.

## Statistical tests

All four tests are significant at α = 0.05:

| Test | Method | Result | p-value |
|---|---|---|---|
| Checkout A/B — revenue | Mann-Whitney U | +16.9% lift | 1.21e-22 |
| Checkout A/B — conversion | Chi-Square | +11.5% lift | 1.13e-38 |
| Champions vs At-Risk spend | Mann-Whitney U | 3.3× higher spend | 6.61e-190 |
| Segment vs return behaviour | Chi-Square | Significant difference | < 0.001 |

## SQL views

The `sql/` folder contains four files that define all analytical views:

- `kpi_queries.sql` — monthly revenue, overall KPIs, region breakdown, product performance, channel, CLV, churn
- `cohort_analysis.sql` — cohort base, monthly activity, retention %, avg retention, new vs returning
- `rfm_segmentation.sql` — raw RFM values, 1–5 scoring, segment labels, segment summary

Run `etl/pipeline.py` to load these into the database and export the results to CSV.
